# omb-media

Public JPEG host for [One Minute Bharat](https://www.instagram.com/) Instagram slide images.

- **Images only.** This repository holds JPEG slides used as `image_url` values for the Instagram Content Publishing API.
- Do not commit secrets, tokens, credentials, or source code here.
- Layout: `<YYYY-MM-DD>/<story_id>/<slide_or_story>.jpg`
- Public URL pattern: `https://raw.githubusercontent.com/sooryahprasath/omb-media/main/<YYYY-MM-DD>/<story_id>/<name>.jpg`
